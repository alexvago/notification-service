# AGENTS.md

This is a simple notification service with two endpoints, one to create notifications and one to get notification by id

# Commands

- lint and format: `pnpm run format`
- start server: `pnpm start`
- run unit tests: `pnpm test`
- run e2e tests: `pnpm test:e2e`

Check the root package.json file for up-to-date commands.

## Pillars

- after changing a file, run linting
- before considering a task complete, verify tests are passing
